**Consistency:** Prefer “Notes” in EN teaser copy if UI already uses it; keep route `/blog`.  
**Stack names:** Next.js, React, TypeScript — untranslated.

**tr-TR hard bans in user-facing copy:** `CTA`, `brief`, `brif`, `Briefing` — use `birincil eylem` / `çağrı`, `proje notu`, `ihtiyacımı yaz`, `keşif`, `fikir`. “Düğme” yalnızca gerçek UI kontrolü için.
